FiddleCraft for Linux (small download)

This small package uses the WebKitGTK web engine already on your computer,
so it is only a few megabytes. It needs the package "webkit2gtk-4.1"
(Arch / CachyOS / Manjaro: webkit2gtk-4.1, Fedora: webkit2gtk4.1,
Debian / Ubuntu: libwebkit2gtk-4.1-0). Most desktops already have it.

Run it:      ./fiddlecraft
Install it for your user (adds FiddleCraft to your app menu):  ./install.sh

If you'd rather not install anything, use the FiddleCraft AppImage instead:
it is bigger because it carries its own copy of the web engine.
